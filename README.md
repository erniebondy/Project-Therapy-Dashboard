## Overview
A web-based application for allowing users to track and schedule with clients

## Features
- Client details
- A monthly note schedule
- To-do list

### To install
- npm install

### To run locally
- npm run start (this will run Vite and the server)

### To run Vite (dev)
- npm run dev

### To run server (dev)
- npm run dev-server


## Technologies
- React
- NodeJS
- SQLite

## Future Improvements
- Real-time chat with other users
- View other users' details associated with a given client
